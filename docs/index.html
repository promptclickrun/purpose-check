The problem

Execution is not the same as judgment.

LLMs can produce a beautiful answer to the wrong question. The failure is subtle: the artifact looks finished, the checklist is green, and the work still does not help the person it was meant to help.

The most expensive mistake is confidently solving the wrong problem.

The operating model

Four stages. One anchor.

Purpose is not a preflight checklist. It is a thread the agent carries from the first decision to the final handoff.

1◎

Should this exist?

Identify who benefits, whether the request is the real problem, and whether a smaller answer would serve the goal better.

2✓

What does done mean?

Define an end state a non-expert could verify. Name the decision or action the output is meant to support.

3↗

Judgment at the forks

Compare meaningful choices against the purpose anchor. Surface only tradeoffs that reach the user or change the stakes.

4◆

Does it hold up?

Return to the anchor. Check for drift, misplaced quality effort, and consequential assumptions before delivery.

Try the anchor

Give the work a north star.

A purpose anchor is one sentence: who this is for, and what gets better for them.

Keep it concrete enough to disagree with. The anchor is not a mission statement.
